# Sistemas_Gerenciamento_Notas_Aluno

 A atividade proposta consiste no desenvolvimento de um programa em Java cujo objetivo é realizar o cálculo da média aritmética de um aluno com base em três avaliações. O sistema deverá solicitar ao usuário a inserção do nome do aluno e, em seguida, a digitação de três notas numéricas correspondentes ao seu desempenho nas avaliações.

* Após a coleta dos dados, o programa deverá:

* Processar os valores informados, efetuando o cálculo da média aritmética​

* Apresentar como saída o nome do aluno e o valor da média calculada, de forma clara e organizada.

* O desenvolvimento desta atividade tem o propósito de exercitar conceitos fundamentais da linguagem Java, incluindo entrada de dados por meio de classe , manipulação de variáveis, operações aritméticas e exibição de resultados utilizando instruções de saída.Além disso, esse projeto possui Java (POO): O código deve ser estruturado usando classes para representar as entidades.

* Interface Gráfica Simples (GUI): Exclusivamente usar a classe javax.swing.JOptionPane para menu, entrada de dados e exibição de resultados.

*   Estrutura de Dados: Fazendo o uso obrigatório da classe Array para gerenciar as notas.
